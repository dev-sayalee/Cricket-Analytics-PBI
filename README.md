# Cricket-Analytics-PBI
Interactive Power BI dashboard built using cricket statistics collected via web scraping from ESPNcricinfo Statsguru. Includes Power Query data transformation, DAX-based player rankings, strike rate categorization, KPIs, and interactive visualizations.
